**Status:** candidate documentation only. The v1.12.4 plugin ZIP has not been published as a public release. The latest published binary remains v1.10.0. Live Torch/AMP validation is pending with the server owner.

The candidate artifact name is `TROA-CleanerPlus-v1.12.4-Manual-Cleanup-Safety.zip`.

## Manual cleanup commands

Preview without deleting:

```text
!cleanerplus status
!cleanerplus scan floatingobjects
!cleanerplus scan corpses
!cleanerplus scan grids
!cleanerplus scan respawnships
!cleanerplus scan npcgrids
!cleanerplus scan asteroids
```

`!cleanerplus scan [module]` only lists eligible candidates. An empty result for a disabled module does not mean that no eligible entities exist.

Run an ordinary module manually with `!cleanerplusadmin now <module>`. The Cleaner+ master switch and that module must be enabled. When global dry-run is on, ordinary modules preview candidates without removing entities. `!cleanerplusadmin now all` queues every enabled module.

## Irreversible asteroid exception

The v1.12.3+ candidate removes whole voxel maps named with the `Asteroid_` prefix and includes `Boulder-` maps by default. It runs after world load and every 120 minutes. It retains a map whose full bounds are within the configured clearance of any live grid (5,000 m by default), protecting asteroid-built bases. It has no age, player-distance, or global dry-run gate. Voxel deletion has no backup or undo.

Review `!cleanerplus scan asteroids` before enabling or running asteroid cleanup. Use `!cleanerplusadmin off asteroids` to disable it. Run that command before `!cleanerplusadmin now all` if asteroid removal is not intended.

## Recovery is not a deep-clean command

`!cleanerplusadmin recovery status|on|off` controls automatic low-SimSpeed sweeps for eligible floating objects and dead characters in enabled automatic modules. It does not clean grids, NPC grids, respawn ships, or asteroids and it does not override global dry-run.
