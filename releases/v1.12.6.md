# TROA Cleaner+ v1.12.6 — Deep Asteroid Cleanup and Player Clearance

Package: `TROA-CleanerPlus-v1.12.6-Deep-Asteroid-Cleanup-Player-Clearance.zip`

## Changes

- Live asteroid cleanup retains the existing 5 km clearance from grids and adds a configurable 10 km clearance from online players. If player positions cannot be read, live-map cleanup fails closed. With no players online, player-distance protection does not block cleanup.
- Orphan asteroid/boulder `.vx2` storage is scanned in the loaded world folder. Pruning waits for cleanup work to drain and a successful world save, verifies no active voxel map references the file, checks player proximity, archives and verifies a copy under `TROACleanerPlusData/RemovedVoxelStorage`, then removes the original world-folder file.
- Files with unrecognized prefixes or coordinates that cannot be safely classified are retained. Archive copies remain recoverable and use disk space.

## Commands

```text
!cleanerplusadmin asteroidstorage status
!cleanerplusadmin asteroidstorage scan
!cleanerplusadmin asteroidstorage prune
```

`scan` is read-only. `prune` queues recognized orphan files for the post-save archival/removal flow. Global dry-run does not block this explicit operation.

## Orphan asteroid storage

Administrators can use `!cleanerplusadmin asteroidstorage status|scan|prune`. Pruning waits for cleanup work to drain and a successful save, checks active references and player clearance, archives and verifies the file, then removes its copy from the world folder. The package default for `Asteroids_MinDistanceFromPlayers` is 10,000 m.
